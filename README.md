# Roblox-AFK-Python-Script


A very simple AFK Script that uses the keyboard and time library to make timed executions of keyboard keys.
It's only good if you're fully AFK and on the roblox screen, you can't ALT+TAB away from it or you're cooked.

Not meant for any specific game only to just keep you in the server while you're away

# How to Install/Use it

First, install the latest version of python to your computer.

Once Installed, install the Keyboard Library keyboard via this command in your terminal "python -m pip keyboard"
(Python 3.14+) 

After the library has been installed, install the file afk.py or copy the contents and paste it to your own python file

Run the program and then tab back into Roblox

Now you're able to walk away from your computer for long periods of time and still be in the server.
